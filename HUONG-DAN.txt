==============================================================================
1. Chép thư mục public/ vào repo web (giữ nguyên đường dẫn) → GitHub Desktop → Commit → Push.
   - public/audio: 4 file nghe Section 1-4
   - public/images/de: bản đồ Section 2 + biểu đồ Writing Task 1
2. Đợi Vercel deploy xong (~2-3 phút).
3. Admin → Đề thi → Tải nhiều đề → chọn "FL4 -- FINAL.json" (tên file tự điền lớp FL4).
Speaking không có trong JSON (GV chấm tay).

ĐÃ CHỈNH SO VỚI ĐỀ GIẤY
 - Reading câu 1-6: đề in bị dính 2 câu vào nhau (câu 1 lẫn câu 2, câu 3 bị tách đôi). Đã tách lại đúng 6 câu,
   khớp đáp án 1C 2A 3D 4C 5A 6E.
 - Passage 3 ghi "Questions 27-40" → sửa thành 28-40.
 - Lỗi đánh máy trong bài đọc: "arc fight" → are right, "tile USA" → the USA, "‘1 really" → ‘I really,
   "die sides" → the sides, "wailing for it" → waiting for it, "re vamped" → revamped, "new’ technology" → new technology.
 - Câu 14-21: học viên chọn từ trong khung (danh sách thả xuống), đúng như đề "using words from the box".
 - Đáp án theo đúng file AK; một số câu nhận thêm cách viết tương đương
   (câu 1 có/không dấu cách, $39 / 39 dollars, sandglass / sand glass, the government…).
